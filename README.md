## 시작 가이드
1. 모두 닉네임을 먼저 설정해주세요.
2. 방장은 컨트롤 패널에서 방을 생성한후 ID를 복사해 배포하세요.
3. 플레이어는 방장 ID를 입력 후 연결하기를 누르세요.
4. 준비가 됐다면 준비 완료를 누르고 대기하세요.
5. 방장은 컨트롤 패널에서 시작버튼을 눌러 게임을 시작하세요.
6. 게임을 재시작하려면 방장은 컨트롤 패널에서 초기화 버튼을 누르세요.

## 게임 설명
1. 제시어가 다른 단 한 명의 범인을 찾는 게임입니다.
2. 30초 내에 힌트를 제시하며 서로의 정체를 유추하세요.
3. 범인은 시민의 제시어를 맞춰 역전 승리할 수 있습니다.
